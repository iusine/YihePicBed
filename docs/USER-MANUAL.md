## 1. 这是什么工具？

PictureBed 是一个 **GitHub 图床管理工具**：

- 它把你在 **GitHub 上创建的仓库**当成"云相册"，图片会以文件形式保存进仓库；
- 图片可以通过 **jsDelivr CDN 加速地址** 外链到博客、笔记、论坛、Markdown 文档中；
- 全部操作在**浏览器网页**内完成，不需要安装客户端；
- **没有服务器**：你的 Token、配置只会保存在自己浏览器的本地存储（localStorage）中；
- 内置三个**纯本地**工具箱（图片不上传服务器）：图片压缩、图片转 Base64、图片加水印。

**它能做什么：**

| 能做的 | 说明 |
| --- | --- |
| 上传图片 | 拖拽或选择本地图片，批量上传到指定 GitHub 仓库目录 |
| 生成外链 | 一键复制 **CDN 直链** 或 **Markdown 图片链接**，粘贴到博客 / 笔记 |
| 管理图片 | 浏览某个目录下的图片，放大预览，或删除不需要的图片 |
| 压缩图片 | 转成 WebP / JPEG / PNG，减小体积后下载 |
| 转 Base64 | 把图片变成一串文本编码，可复制或存成 `.txt` |
| 加水印 | 给图片加文字水印（可调大小、颜色、透明度、位置）并导出 |

**它不能做什么（提前说明，避免误会）：**

- 不能"修改"已上传的图片——上传同名文件会被拒绝（GitHub 规则），请先删除旧文件或换一个文件名；
- 不提供图片搜索、相册分组等高级管理功能；
- 不能访问他人私有仓库（除非你有相应 Token 权限）；
- 单次只能管理**一个目录内最多 1000 个文件**的范围（GitHub 接口限制）。

| 准备项 | 说明 |

## 3. 五分钟快速上手

按顺序完成下面 5 步，即可正常使用：

| 步骤 | 操作 | 位置 |
| --- | --- | --- |
| ① | 在 GitHub 创建一个**公开**仓库，例如 `Image-bed` | github.com → New repository |
| ② | 生成一个 **Personal Access Token**（勾选 `public_repo` 权限），复制并保存好 | github.com → Settings → Developer settings → Tokens |
| ③ | 打开本工具「图床配置」，粘贴 Token → 点【查询】→ 点【保存配置】 | 左侧菜单 → 图床配置 |

| ⑤ | 鼠标移到图片上，点图标复制 **CDN 链接** 或 **Markdown 链接**，粘贴使用 | 图床管理图片网格 |

> 若页面上有【使用帮助】菜单，其中内置了带截图的图文教程，可对照操作。

## 5. 详细操作指南

### 5.1 第一步：创建 GitHub 仓库（图床）

1. 登录 GitHub，点击右上角 **+** → **New repository**；
2. 填写仓库名（例如 `Image-bed`），**选择 Public（公开）**；
3. 可以勾选"Add a README file"，其它保持默认，点击 **Create repository** 完成创建。

> 为什么必须公开？公开仓库才能使用 jsDelivr CDN 加速外链。若只自己看、不对外分享，也可以选 Private，
> 但 CDN 加速链接将无法访问，图片也无法在网页/博客中正常显示。

### 5.2 第二步：生成 GitHub Token（访问凭证）

Token 相当于本工具访问你 GitHub 账号的"钥匙"。生成步骤：

1. 打开 [GitHub Token 页面](https://github.com/settings/tokens)（Settings → Developer settings → Personal access tokens）；
2. 点击 **Generate new token**（若提示选择类型，选 **Tokens (classic)**）；
3. 填写 Note（备注，如 `PictureBed`），有效期可按需选择；
4. 在权限勾选区勾选 **`public_repo`**（访问公开仓库、读写文件所需的最小权限）；
5. 点击页面底部的 **Generate token**；
6. 页面会显示一串以 `ghp_` 开头的字符，**立即复制并妥善保存**。

> ⚠️ 重要提醒：
> - Token 只会完整显示 **一次**，关闭页面后就看不到了，忘记只能重新生成；
> - 不要截图发群、不要提交到代码仓库；
> - 若怀疑泄露，回到 Token 页面点击 **Delete / Revoke** 立即作废。

### 5.3 第三步：配置 Token（图床配置页）

1. 点击左侧菜单 **图床配置**；
2. 在输入框粘贴刚生成的 Token（输入框支持点击小眼睛查看明文）；
3. 点击【查询】：下方会显示你的 GitHub 头像和用户名，说明 Token 有效；
4. 点击【**保存配置**】：Token 与用户信息保存到当前浏览器，之后每次打开都自动生效。

**按钮说明：**

| 按钮 | 作用 |
| --- | --- |
| 查询 | 验证 Token 并拉取你的账号信息（若未保存，需要先查询才能保存） |
| 保存配置 | 把 Token 与账号信息保存到浏览器本地 |
| 清除配置 | 删除本地保存的 Token 与账号信息（下次使用需重新配置） |

**CDN 站源设置（可选，一般保持默认）：**

- 页面下方的"CDN 站源"用于决定生成的图片直链前缀，默认是 `jsd.onmicrosoft.cn`；
- 上传成功后的链接格式为：`https://站源/gh/用户名/仓库/文件路径`；
- 如果你的图片链接打不开（部分地区 jsDelivr 节点不稳定），可以在这里把站源换成列表中推荐的其它节点（如 `fastly.jsdelivr.net`、`testingcf.jsdelivr.net` 等），点击【保存为默认站源】长期生效。

### 5.4 第四步：上传与使用图片（图床管理页）

> 若尚未配置 Token，本页会提示你前往「图床配置」完成配置后再使用。

#### 5.4.1 选择仓库与目录

1. **仓库**：下拉框选择要用作图床的仓库；
2. **目录**：级联选择框逐层选择文件夹（先展开"根目录"再逐层点击；**不选则默认仓库根目录**）；
3. 点击【**查询**】，右侧即以缩略图网格列出该目录下所有图片。

> 💡 已选择的仓库与目录会被记住，刷新页面后自动恢复，无需每次重选。

#### 5.4.2 查看图片

- 单击任意缩略图 → 进入**大图预览**模式（可放大、缩小、旋转、切换上一张/下一张，点关闭或按 Esc 退出）；
- 顶部三条黄色提示条（如有）说明了列表规则，点"不再提示"后可隐藏：
  1. 只显示常见图片格式（jpg / png / gif / webp / svg 等）；
  2. 单个目录最多能查询 1000 个文件；
  3. 同名文件不能重复上传（会报 422 错误）。

#### 5.4.3 复制图片链接

鼠标悬停到图片上，右下角浮现 3 个圆形按钮：

| 图标 | 按钮含义 | 复制到的内容示例 |
| --- | --- | --- |
| 链条 | 复制 **CDN 链接** | `https://jsd.onmicrosoft.cn/gh/用户名/仓库/图片.png` |
| M | 复制 **Markdown 链接** | `![图片.png](https://…/图片.png)` |
| 垃圾桶 | **删除**该图片（需二次确认） | — |

- 复制后直接粘贴到 Typora、语雀、博客、论坛即可显示图片；
- **Markdown 链接**最适合 Markdown 写作场景（博客 / 笔记软件 / README）；
- 删除是不可恢复操作，确认后图片文件会从 GitHub 仓库中移除。

#### 5.4.4 上传图片

1. 点击【上传】按钮，右侧弹出"上传文件"面板；
2. 选择**命名方式**：
   - **使用源文件名**：保持你电脑上的文件名（如 `photo.png`）；
   - **使用 UUID 文件名**：自动生成随机文件名（如 `d1c2….png`），可避免重名冲突，更适合长期外链；
3. 确认顶部显示"当前目录"正确（显示将存放的仓库路径）；
4. （可选）开启【自定义目录】并输入子目录，例如 `oldFolder/newFolder/`，图片会传到该子目录，而不是当前选中目录；
5. 将图片**拖入虚线区域**，或**点击区域**选择文件（支持多选）；
6. 点击【**确定上传**】，等待每张图片提示"上传成功"；
7. 关闭抽屉，重新点击【查询】即可看到新上传的图片。

> ⚠️ 注意：
> - 上传是真实的 GitHub 写操作，请勿反复连点按钮（按钮已做 3 秒防重限制）；
> - 批量上传时工具会自动错开提交间隔，请耐心等待全部提示成功；
> - 上传**同名**文件会失败（GitHub 返回 422），请先删除旧文件或用 UUID 命名。

#### 5.4.5 CDN 加速与 GitHub 源站切换

第二行有个开关：

- 开（**CDN 加速**，默认）：缩略图与复制链接均走 jsDelivr CDN，访问快；
- 关（**GitHub 源站**）：页面显示 GitHub 原始链接的缩略图。

> 说明：无论开关状态如何，"复制 CDN 链接 / 复制 Markdown 链接"生成的都是 CDN 地址；
> 如果只想拿 GitHub 原始地址，可到 GitHub 仓库网页中获取。

### 5.5 使用帮助页

左侧菜单【使用帮助】内置了一个分步图文向导，点击"下一步 / 上一步"浏览：

1. **创建仓库**（跳转 GitHub 新建仓库页面）；
2. **生成 Token**（跳转 Token 页面，勾选 public_repo）；
3. **使用**（配置 Token → 查询 → 上传）。

适合新手边看截图边操作，与本文档 5.1–5.4 内容一致。

## 6. 工具箱使用指南

> 三个工具箱的图片都**只在本地浏览器中处理，不会上传到任何服务器**，可放心使用。
> 每个工具都支持：**拖拽**、**粘贴**（Ctrl/Cmd + V 直接粘剪贴板截图）、**点击选择**三种方式添加图片。

### 6.1 图片压缩

把大图压缩变小，适合发博客、传图床前瘦身。

**操作步骤：**

1. 进入左侧菜单 **工具箱 → 图片压缩**；
2. 添加一张或多张图片（不限制大小与数量）；
3. 设置参数：
   - **输出格式**：WebP（推荐，体积最小）/ JPEG / PNG（无损）；
   - **质量**：10%–100%，数值越低体积越小、画质损失越大（PNG 时为无损，质量条自动禁用）；
4. 点击【**开始压缩**】，逐张处理后显示"原大小 → 新大小"与节省百分比；
5. 点击单张【下载】或【下载全部】保存结果。

**状态与标记说明：**

| 显示 | 含义 |
| --- | --- |
| 绿色 -xx% | 压缩后变小了 xx% |
| 灰色 "变大 xx%" | 该图压缩后反而变大（常见于 PNG 无损转 PNG / 已高度压缩的图），此时建议换格式或保持原图 |
| 红色警告图标 | 处理失败，可点击【开始压缩】重试 |

### 6.2 图片转 Base64

把图片变成一段文本编码（Base64），可直接内嵌进 HTML / CSS / 接口数据中。

**操作步骤：**

1. 进入 **工具箱 → 图片转 Base64**；
2. 添加图片（支持多张）；
3. 用顶部开关选择输出形式：
   - **包含 data:image 前缀**：适合直接当作图片地址使用（如 `<img src="data:image/png;base64,…">`）；
   - **仅纯 Base64**：只要编码本体；
4. 每张图下方显示编码预览（可滚动），点击【复制】或【下载 .txt】保存。

### 6.3 图片水印

给图片加上"文字水印"，防止图片被随意盗用或标识出处。

**操作步骤：**

1. 进入 **工具箱 → 图片水印**；
2. 添加一张图片（左侧实时预览水印效果）；
3. 在右侧面板调整参数（修改后约 0.1 秒自动刷新预览）：

| 参数 | 说明 |
| --- | --- |
| 添加水印 | 总开关（关闭后仅导出原图） |
| 水印文字 | 最长 20 字，默认 "Picture Hosting" |
| 水印大小 | 1–12 档，右侧实时显示对应像素字号 |
| 颜色 | 调色板选择，另有 6 个快捷颜色 |
| 透明度 | 5%–100% |
| 位置 | 左上 / 右上 / 左下 / 右下 / 居中 |
| 导出格式 | PNG（保留透明背景）/ JPEG（白色背景） |

4. 点击【**下载图片**】，得到 `原文件名_watermark.png`（或 `.jpg`）。

> 提示：深色图片上建议使用**浅色水印**（水印自带轻微阴影，浅色字更清晰）；JPEG 会以白色填充背景输出。

## 7. 常见问题 FAQ

**Q1：提示 "Bad credentials" / 查询不到用户？**
Token 无效或已过期。回到【图床配置】，重新生成 Token 并保存。

**Q2：查询时报错、看不到仓库或目录？**
- 检查 Token 是否勾选了 `public_repo`；
- 私有仓库需要更高权限的 Token，且其内容无法走 jsDelivr 公网 CDN；
- 确认仓库确实存在且目录未超过 1000 个文件。

**Q3：上传时报 422 错误？**
同名文件已存在。删除原文件后重传，或改用"UUID 文件名"。

**Q4：上传报 409 冲突？**
批量上传过快偶发，工具已自动错峰，等待片刻重试即可。

**Q5：复制的图片链接打不开？**
- jsDelivr 节点有缓存或地区差异：到【图床配置】把 CDN 站源切换为其它推荐节点再试；
- 仓库是私有仓库时 CDN 必然 404：请确认仓库为 Public，且文件确实存在；
- jsDelivr 缓存偶尔滞后，新上传文件稍等 1–2 分钟。

**Q6：为什么列表里看不到某张图片？**
列表只显示常见图片格式（jpg / jpeg / png / gif / webp / svg / bmp / tiff / avif / ico 等）。
`.txt`、`.zip` 等非图片文件不会出现在列表中（但它们确实在仓库里，可在 GitHub 网页查看）。

**Q7：换电脑 / 换浏览器后配置没了？**
配置保存在**当前浏览器本地**，不会云端同步。请在新浏览器重新配置 Token（5.3 节）。

**Q8：图片压缩后反而变大？**
无损输出或原图已被高度优化时会出现。可改用 WebP + 适当质量，或放弃压缩。

**Q9：工具箱处理大图很慢 / 卡顿？**
图片处理在本地进行，超大图（数 MB 以上）需要较多内存，建议先压缩再用。

**Q10：忘记 Token / 需要换 Token？**
在 GitHub Token 页面重新生成，然后到【图床配置】重新保存即可；旧的可在 GitHub 上删除。

## 8. 安全与隐私须知

| 事项 | 说明 |
| --- | --- |
| Token 存储位置 | 仅保存在**当前浏览器的 localStorage**，不会发送给本站之外的任何第三方（请求直接发给 GitHub 官方 API） |
| 建议权限 | 使用仅含 `public_repo` 的最小权限 Token；若管理私有仓库，请理解 Token 能读写哪些内容 |
| 公共电脑 | 不要在公用 / 他人电脑上"保存配置"，使用后记得【清除配置】并退出浏览器 |
| 工具箱图片 | 压缩 / Base64 / 水印均为**纯本地处理**，图片不会上传网络 |
| 上传行为 | 上传、删除操作会真实修改你的 GitHub 仓库（每次形成一个 commit），请确认选中的仓库与目录正确 |
| 隐私仓库 | 若仓库内有敏感文件，本工具目录浏览与查询会将其列出（仅列图片格式）；请勿把敏感内容与图床放在同一仓库 |

## 9. 清除本工具的本地数据

需要彻底清除本工具留在浏览器里的数据时：

1. 打开【图床配置】→ 点击【清除配置】——清除 GitHub Token 与用户信息；
2. 其余本地项（记住的仓库/目录、CDN 站源、主题、提示条状态）按浏览器清除方式处理：
   - Chrome / Edge：地址栏点锁形图标 → Cookie 和网站数据 → 删除该站点的数据；或 F12 → Application → Local Storage → 删除对应键；
   - 或直接清除该站点所有本地存储后刷新页面。

> 清除后相当于"第一次使用"，重新按本文档 5.3 节配置即可。
